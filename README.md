# 거북목·자세 교정 도우미

웹캠 영상은 브라우저에서만 처리하고 MediaPipe 관절 좌표만 로컬 FastAPI 서버로 보내 자세를 추정하는 학습형 웹앱입니다. 의료 기기가 아니며 결과는 추정치입니다.

## MLOps 사이클

1. 데이터 수집: 바른/나쁜 자세 좌표를 세션별 JSONL로 저장
2. 학습·검증: scikit-learn 모델 학습, 정확도 계산, 검증 게이트 적용
3. 버전 관리: `v1`, `v2` 모델과 metrics 저장, 활성 모델 및 롤백 지원
4. 서빙: FastAPI `/api/predict`가 활성 모델로 실시간 판정
5. 모니터링: 신뢰도와 판정 상태를 표시하고 드리프트를 안내
6. 재학습: 새 데이터를 수집해 새 모델 버전 생성

## 설치 및 실행

Python 3.11 이상과 인터넷 연결(MediaPipe CDN/model 다운로드)이 필요합니다.

```powershell
pip install -r requirements.txt
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

브라우저에서 http://127.0.0.1:8000 을 열고 카메라 권한을 허용합니다. 첫 실행 시 `data/`와 `data/models/`는 코드가 자동 생성합니다.

## 사용 순서

1. 카메라 시작을 누릅니다.
2. 바른 자세 녹화와 나쁜 자세 녹화를 각각 실행합니다.
3. 최소 샘플 수를 채운 뒤 모델 학습하기를 누릅니다.
4. 활성 모델로 실시간 판정을 확인합니다.

## 개인정보 및 저장 방식

웹캠 이미지는 서버로 보내거나 저장하지 않습니다. 브라우저에서 추출한 관절 좌표만 로컬 `data/samples.jsonl`에 저장하고, 모델과 metrics만 `data/models/`에 저장합니다. 삭제 버튼으로 자료와 모델을 각각 삭제할 수 있습니다.

## 테스트

```powershell
python -m pytest -q
```

합성 좌표는 테스트에서만 사용되며 실제 서비스 모델로 배포되지 않습니다.
